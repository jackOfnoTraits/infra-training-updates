## Description

Theme: System Diagnostics

Today’s commands share a common theme of inspecting system hardware, identifying storage leaks, and peeking behind the curtain of running system logs.

Today’s Toolkit:

1. lscpu - Inspect CPU architecture, core count, and virtualization specs.
2. free -h - Display total, used and available RAM and swap space.
3. df -h - Check remaining storage space across all mounted drives and partitions.
4. du -sh * - Calculate directory disk consumption to catch file bloat instantly.
5. top - Live CPU, memory, and process usage
6. ps - Static snapshot of currently running processes
7. lsblk - Disks, partitions, and mount points
8. journalctl -xe - Inspect systemd system logs with real-time error details.
9. uptime - View system run time, active user sessions, and 1/5/15 minute load averages.
10. history - Recall and search pat terminal operations.
Acceptance Criteria:

- Execute all 10 commands in you Ubuntu terminal.
