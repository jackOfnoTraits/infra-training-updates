## Description

Explore and practice 10 Ubuntu-compatible Linux commands in a Multipass virtual machine on macOS to understand kernel configuration, process management, namespaces, memory inspection, and system administration.

Commands to Practice:

1. systemd-cgtop — Monitor resource consumption by control groups.
2. lsns — Inspect Linux namespaces.
3. pr — Format text into paginated output.
4. od — Inspect raw file contents.
5. stat — Examine file metadata.
6. getent — Query system databases.
7. sysctl — Inspect and configure kernel parameters.
8. ulimit — Manage process resource limits.
9. pmap — Inspect process memory maps.
10. base64 — Encode and decode data.
