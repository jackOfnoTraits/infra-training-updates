## Description

Task Heading

Database Creation, Table Design, and SQL Query Execution Using Dataset 2

Description

Use the second dataset already provided for the previous task. Create a new and separate database for this dataset and design suitable tables based on its columns and data types using SQLite or MySQL Workbench.

Import or insert the dataset records into the tables and execute at least 7 different SQL queries, using different combinations of SQL commands and clauses such as SELECT, WHERE, ORDER BY, GROUP BY, aggregate functions, HAVING, and JOIN wherever applicable.

For each query, attach:

1. The SQL query executed.
2. The corresponding output or result table.
3. A brief explanation of the query and its result.
Capture the outputs and compile the queries and results into a document for submission.

Expected Outcome: A separate database containing the second dataset, properly structured tables, and at least seven executed SQL queries with their corresponding outputs and explanations.
