## Description

Description:

Practice 10 Linux commands for incident investigation, file integrity verification, process analysis, system auditing, and crash diagnostics in a RHEL environment.

Commands to Practice:

1. find — Identify recently modified files.
2. pstree — Inspect process hierarchies.
3. strace — Trace system calls.
4. sha256sum — Verify file integrity and detect changes.
5. xxd — Inspect raw file contents.
6. ausearch — Search Linux audit logs.
7. systemctl list-timers — Inspect scheduled system tasks.
8. ldd / readelf -d — Inspect shared-library dependencies.
9. getent — Query system account and directory databases.
10. coredumpctl — Investigate application crashes and core dumps.
