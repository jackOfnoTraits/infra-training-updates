## Description

Design and develop an interactive and visually appealing Sales Performance Dashboard using Microsoft Power BI. The dashboard should provide meaningful insights into sales performance through key performance indicators (KPIs), charts, filters, and interactive visualizations.

1. KPI Development and Formatting

- Create KPI cards to display important business metrics.
- Include the following KPIs:  - Total Revenue - Total Orders - Total Customers - Average Order Value
- Apply appropriate number and currency formatting to each KPI.
- Enable meaningful titles for all KPI cards.
- Maintain consistent formatting, alignment, and font sizes.
2. Data Visualization

Create appropriate visualizations to represent sales performance and business trends.

Include:

- Bar Chart: Compare revenue across different product categories.
- Line Chart: Analyze monthly revenue trends.
- Pie/Donut Chart: Display revenue contribution by category.
- Card Visuals: Highlight important business KPIs.
Select appropriate visual types based on the data and the insights they communicate.

3. Filters and Slicers

Implement interactive filters and slicers to allow users to explore the dashboard dynamically.

Include:

- Category-based filtering.
- Date-based filtering.
- Customer-based filtering.
- Other relevant business filters.
Ensure that slicers interact correctly with the dashboard visuals.

4. Data Analysis and Insights

- Create a date hierarchy to analyze monthly sales performance.
- Identify revenue trends across different months.
- Compare category-wise revenue.
- Analyze average order value.
- Explore different combinations of filters to identify meaningful business insights.
5. Dashboard Design and Formatting

- Create a clean, professional, and user-friendly dashboard layout.
- Arrange KPI cards in a single row wherever appropriate.
- Use consistent colors, fonts, titles, and formatting.
- Highlight important business metrics and trends.
- Adjust visual sizes and positions for better readability.
- Avoid unnecessary information and overcrowded visuals.
6. Final Dashboard Requirements

- Ensure all visuals are properly formatted and interactive.
- Verify that filters and slicers work correctly.
- Maintain consistency throughout the dashboard.
- Save the completed dashboard as a Power BI (.pbix) file.
7. Documentation

Prepare documentation explaining:

- Dashboard objectives.
- KPIs and their calculations.
- Visualizations used and their purpose.
- Filters and slicers implemented.
- Key insights obtained from the dashboard.
Expected Deliverable: A fully functional, interactive Power BI Sales Performance Dashboard (.pbix) accompanied by a brief documentation report.
