## Description

# | Command | What it does | Practical challenge
1 | mtr | Combines traceroute and ping for network diagnostics. | Identify packet loss along a network route.
2 | ipcalc | Calculates and analyzes IPv4/IPv6 network ranges. | Calculate subnet ranges and usable addresses.
3 | arp-scan | Discovers devices on a local network using ARP. | Identify devices connected to your LAN.
4 | nc | Tests TCP/UDP connectivity and transfers data. | Check whether a remote port is reachable.
5 | fallocate | Quickly allocates disk space for files. | Create a large test file without writing all its contents.
6 | lsattr | Displays special filesystem attributes. | Identify immutable files.
7 | chattr | Changes special filesystem attributes. | Make a test file immutable and restore it.
8 | watch | Repeatedly executes and displays a command. | Monitor system resources continuously.
9 | timeout | Limits how long a command can run. | Prevent a script from running indefinitely.
10 | strace | Traces system calls and signals. | Investigate why a process cannot access a file.
