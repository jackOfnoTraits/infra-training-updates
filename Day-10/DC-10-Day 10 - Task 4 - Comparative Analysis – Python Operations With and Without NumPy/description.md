## Description

Select a suitable example, such as student marks analysis, sales data analysis, or product price calculations, and implement the same operations using standard Python and NumPy.

Compare both approaches to understand the differences in code simplicity, execution time, memory usage, and suitability for handling large datasets.

Task Requirements:

1. Example Selection: Choose one real-world example, such as calculating student marks, analyzing sales figures, or processing product prices.
2. Implementation Without NumPy: Use standard Python data structures, such as lists, loops, and built-in functions, to perform the required operations.
3. Implementation With NumPy: Use NumPy arrays and functions to perform the same operations.
4. Operations to Perform: Include calculations such as sum, mean, minimum, maximum, and element-wise operations.
5. Code Comparison: Explain the differences in code length, readability, simplicity, and implementation.
6. Performance Comparison: Measure execution time for both approaches using a sufficiently large dataset. Use repeated measurements for a fair comparison.
7. Results and Analysis: Present the outputs and compare the advantages and limitations of each approach.
8. Documentation: Prepare a report containing the problem statement, both code implementations, outputs, performance results, and conclusion.
Expected Deliverable:

A Python program or Jupyter Notebook containing both implementations, their outputs, a performance comparison, and a brief report explaining when to use standard Python and when to use NumPy.

Acceptance Criteria:

- The same example and operations are implemented with and without NumPy.
- Both implementations produce equivalent results.
- Execution time is measured using a consistent methodology.
- Differences in syntax, performance, and usability are documented.
- The final comparison and conclusion are submitted for review.
