## Description

Import NumPy and Pandas, create a sample dataset using a Pandas DataFrame, add a new calculated column using existing columns, and compute relevant statistical measures to understand the data.

Task Requirements:

1. Import Libraries: Import NumPy as np and Pandas as pd.
2. Create a Sample Dataset: Create a DataFrame using a real-world example, such as product sales, student marks, or employee salaries.
3. Create a Calculated Column: Add a new column derived from existing columns. For example, calculate total sales using quantity multiplied by unit price.
4. Calculate Statistics: Compute the mean, median, standard deviation, minimum, and maximum of the selected numerical columns using NumPy and Pandas.
5. Analyze Results: Interpret the calculated statistics and explain what they reveal about the dataset.
6. Display Output: Display the original DataFrame, the updated DataFrame with the new column, and the calculated statistical results.
Tools Required:

- Python
- NumPy
- Pandas
- Jupyter Notebook or Google Colab
Expected Deliverable:

A Python script or Jupyter Notebook containing the sample dataset, calculated column, statistical calculations, displayed outputs, and a brief explanation of the results.

Acceptance Criteria:

- NumPy and Pandas are imported successfully.
- A sample DataFrame is created with appropriate numerical columns.
- A new calculated column is added correctly.
- Mean, median, standard deviation, minimum, and maximum are calculated.
- Results are displayed clearly and interpreted correctly.
- The completed notebook or script is submitted for review.
