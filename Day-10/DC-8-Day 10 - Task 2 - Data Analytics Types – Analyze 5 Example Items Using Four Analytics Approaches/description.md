## Description

Identify five realistic business problems and analyze each using the four types of data analytics:

- Descriptive: What happened?
- Diagnostic: Why did it happen?
- Predictive: What might happen next?
- Prescriptive: What should we do?
Document the scenarios, key findings, and recommended actions in a Markdown file.

Acceptance Criteria:

- Five distinct business scenarios are covered.
- All four types of analytics are addressed for each scenario.
- A comparison table summarizes the findings.
- The final Markdown file is saved and accessible.
